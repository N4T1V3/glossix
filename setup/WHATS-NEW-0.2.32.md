# Glossix 0.2.32

Larger practice descriptions and buttons, smaller account level and daily challenges. Dictionary book pages show 6–8 entries, with search, word-type filters, alphabetical/reverse/English/topic sorting and page jump. Full definitions open in a popup.

Friends, incoming requests and sent requests each preview five items. Remaining items open in a popup with five per page. Leaderboards show ten rows and a separate current-user rank strip for both scopes and periods.

Profiles use a compact two-column desktop layout. Owner support text is expandable. Account information is concise and customization remains on the Profile page. Settings are split into tabs.

Notes support up to 20 named tabs; existing notes load into My notes. Tabs and text are saved together using the existing private notes service and revision history. Autosave runs after typing, when leaving the app window or tab, and when navigating away. Save remains available. Unsaved drafts stay local during connection failures; conflicts still require review. The editor scrolls inside a fixed notebook page. The existing 200,000-character notebook storage limit still applies. Do not open tabbed notes in an older app version, which would show the stored notebook format as text.

No additional SQL is required if the earlier profile, friends, leaderboard and private-notes migrations are already installed. No production data was changed to test this layout. Long definitions, settings, and full lists can be opened as separate panels. Small/mobile windows may still need scrolling to keep controls readable.
