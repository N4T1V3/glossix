# Russian word review — first pass (0.2.34)

Processed the original 1,489 unresolved entries for usage and proposed meanings. Archived 101 entries from dictionary browsing, retaining their IDs and a recoverable copy: 10 uncommon variants/spelling errors with translated alternatives, one Belarusian headword, and 90 very low-frequency entries. Kept 1,388 entries for meaning review.

1,125 remaining entries are removal candidates, not automatic removals. A zero wordfreq score means absent from that corpus, not that a word is never used. Very-rare archival used an observed Zipf score between 0 and 1.5, a low OpenRussian rank (50,000 or later), and a manual exception list for useful modern/domain words. Adjective forms and е/ё alternatives were checked. This remains an estimate of general usage; specific fields and regions may use these words more often.

Proposed meanings are sorted into meaning categories. 90 have Glossix-drafted interpretations/corrections; the rest have clearly labelled offline machine suggestions or need manual interpretation. Machine suggestions can contain serious semantic errors. None of these proposals is an approved practice answer. The dictionary's Entries needing review shows proposed English meanings with that status.

Open russian-word-review.html in the preview to search, filter, page through and edit proposals. Your decisions save locally; Download your review exports JSON for the next correction pass. CSV, full JSON and the removal archive are provided separately.

No SQL update. No saved reference IDs or notes were deleted. Archived entries remain readable from saved-word collections and excluded from practice until a verified meaning is added.
