# Glossix 0.2.5

50 profile designs, with vibrant colours, decorative borders, waves and geometric patterns. Unlocks span levels 1–1000.

Review profile-background-review.html in your browser.

Run SUPABASE-PROFILE-DESIGNS.sql once to add all designs to the reward catalogue; it is safe to rerun and retains previous selections/grants. Existing owner grant commands apply to every new design.

Copy the contents of github-source into your repository, commit and push, build in GitHub Actions, then publish v0.2.5 with its matching EXE, blockmap and latest.yml.
